# 🧭 用户使用指南

> 本指南面向普通用户：如何安装、导入源、日常使用与常见问题。想了解特色能力见 [核心特色详解](features.md)；想编写源见 [开发者指南](developer-guide.md)。

## 3.1 获取与安装

- **使用预编译包**：从项目的 Releases 页面下载对应平台安装包（如 Android APK、Windows 安装程序）。具体发布渠道以仓库 Releases 为准。
- **从源码构建**：参见 [开发者指南 · 环境准备与构建](developer-guide.md#41-环境准备)（推荐开发者）。

## 3.2 首次启动与导入源（关键）

由于本应用**不内置任何源**，首次启动后是空的，需要自行导入：

1. 在应用内找到「源管理 / 导入源」入口；
2. 粘贴一份源 JSON，或选择本地的源 JSON 文件；
3. 导入成功后，该源对应的站点内容即可在首页 / 分类中浏览，**无需改动应用代码**。

> 源 JSON 应该长什么样、有哪些字段？见 [开发者指南 · 源编写教程](developer-guide.md#45-源即插件如何编写与贡献一个源)。

## 3.3 日常使用

- **浏览 / 搜索**：在首页或分类中浏览，使用搜索按关键词检索；
- **阅读 / 观看**：点击进入详情，选择章节开始阅读漫画 / 小说，或播放影视（支持弹幕、多线路、嗅探兜底）；
- **下载**：对感兴趣的内容使用离线下载，便于无网络时查看；
- **筛选**：部分源提供标签 / 分类筛选，可快速定位内容；
- **收藏分组 / 评分 / 评论**：把喜欢的条目加入分组收藏，可打本地分、写短评，也可在支持的源上参与网站评论；
- **Bangumi 同步**：可选登录 Bangumi 账号，把收藏 / 进度 / 评分同步过去；
- **网络配置**：连不上 / 需要代理时，可在设置中调整代理、DNS、Hosts 等（支持按源单独覆盖）。

## 3.4 常见问题

- **为什么看不到任何内容？** 多半是还没导入源。请先按 3.2 导入至少一个源。
- **导入源后仍是空白？** 检查源是否适用于当前网络环境，或该站点是否需要登录态 / 反爬处理（可尝试由源作者更新源脚本）。
- **仓库里没有源，去哪找？** 源由社区共享维护；请通过社区渠道获取并自行评估其合规性与内容合法性。
- **部分内容不显示？** 应用默认开启年龄限制，`mature`（18+）源默认隐藏；如需显示，请到设置中开启「年龄限制内容」并自行确认符合所在地法律与年龄要求。
