# 📖 核心特色详解

> 本文档详解 NexHub 的几项**最具特色、也最容易让人误解**的能力。想了解安装使用，见 [用户使用指南](user-guide.md)；想编写源，见 [开发者指南](developer-guide.md)。

NexHub 与同类工具最大的不同，在于它把「解析能力」彻底从应用里剥离出来，交给社区用源文件维护。下面逐项展开。

## 2.1 源即插件 · 共创模式（核心中的核心）

这是 NexHub 的灵魂，请优先理解：

- **解析逻辑与站点完全解耦**：应用代码里没有任何「为某个站点写死的逻辑」。一个站点能不能被解析，只取决于你有没有一份对应的源 JSON；
- **声明式 + 脚本式两种写法，自由组合**：
  - **声明式**：用 XPath / JSONPath / CSS 选择器描述「列表项在哪、标题在哪、章节链接在哪」。适合结构稳定的服务端渲染页面，零代码、改起来直观；
  - **脚本式**：在源里内嵌一段 JavaScript（在 `flutter_js` 安全沙箱中执行），用来处理动态渲染、登录态注入、加密参数拼接、接口签名等复杂场景；
- **多引擎调度 `ResolverRegistry`**：应用读到一个源后，会按它的 `parser.type` 自动选择解析器——
  - `builtin` / `xpath` / `jsonpath` / `css` → 声明式解析；
  - `script` → 交给 JS 沙箱执行源内脚本；
  - `hybrid` → 按路由在「声明式 / 脚本式」之间智能切换；
  - `webview` → 借助内嵌浏览器渲染后再抽取；
- **同一个引擎，无限个源**：社区每天都能新增、修正源，而应用本身几个月不更新都照样能用。

> 一句话：**应用是书架，源是书。书架不挑书，书也不挑书架。**

## 2.2 源 JS 沙箱的运行铁律（写源的人必读）

源内脚本运行在 `flutter_js`（QuickJS 内核）沙箱中，与 Dart 主线程隔离。这里有两条**经过真机验证**的重要约束，理解它们能少走很多弯路：

1. **异步通道是受限的**：沙箱对 `Promise` / `async` 的支持并不完全。需要发起 HTTP 请求拿数据时，源不应自己 `await fetch`，而是返回一个「协议对象」告知引擎「去哪个 URL 取数据、取回后用哪个函数处理」，由 Dart 侧统一抓取后再把数据回灌给同步处理函数；
2. **同步处理、桥接取数**：把「计算」和「取数」分开——取数交给引擎的桥接通道，源脚本只做纯同步的解析与转换。这套「通用协议」对纯同步脚本零影响，对需要联网的脚本则提供唯一可靠通道。

掌握这两点，你就能在源里实现「登录态抓取、接口签名、动态分页」等高级效果，而不会卡在「为什么 async 不生效」。

## 2.3 首页多板块与动态筛选（所见即所得）

为了让不同源的首页体验一致又不雷同：

- **首页多板块**：源可以声明 `homeSections`（自己定义首页要展示哪些板块、各板块叫什么）；如果源没声明，应用会**自动**根据源的分类生成「最新 + 各分类」多个板块（自动跳过「全部 / 汇总」这类聚合项，最多 8 块），让旧源无需重新导出就能立刻拥有多板块首页；
- **动态筛选**：源可以声明 `filters.groups` 来提供筛选维度。其中**分类本身已经是顶部 Tab，不会重复变成筛选组**，避免「筛选栏和分类栏长得一样」的尴尬；当源提供标签路由 + 标签清单时，应用会自动生成「标签筛选」，且选项的 `value` 用的是站点真实的标签 slug（例如古风站的 `gufeng` 而非带连字符的 `gu-feng`），`label` 用中文显示名——保证筛出来的内容**准确对得上站点**。

> 这套机制的关键教训是：**先确认 URL / slug 拼写，再判断页面是不是 JS 渲染**。曾经有源因为标签 slug 拼错（多了连字符）导致返回空壳页，被误判为「SPA 客户端渲染」而走了搜索兜底接口，结果搜索是全文标题匹配、内容不准。拼写正确后，服务端渲染页直接就能抓，内容才准确。

## 2.4 漫画阅读器（专项打磨）

不是「能看」就行，而是针对真实痛点做过专项修复：

- 支持**双页 / 单页**两种版式，翻页手势、选话（选章节）、左右滑动切换；
- 专门处理过「**区间超屏**」（超长条漫跨屏）、「**图片缺失**自动跳过占位」、「**进度回跳**」（阅读进度被错误重置）等常见问题；
- 阅读进度与书签持久化，关掉再打开能回到原处。
- **v2.0.0-beta.2**：新增夜览暖色盖层、睡眠定时（按分钟 / 按话数）、双击三态 / E-Ink 刷新 / ICC 校色、自动收藏封面、预加载数量可配（1–16）、键盘快捷键补全与鼠标滚轮速度可调，并做了资源 / 内存优化（归档临时目录回收、图片缓存按内存预算、退后台冲刷进度）。

## 2.5 小说阅读器（六条体验原则）

小说阅读器遵循一组明确的体验原则，确保「设置真的生效、不互相打架」：

1. **样式可共存**：字体、字号、行距、边距、主题、亮度等样式以「组合 / 位标志」共存，而不是单选覆盖——你开了护眼又开了夜间，二者同时生效；
2. **即时生效 + 持久化**：改任何设置立刻看到效果，并写入本地，下次打开还是你调的样子；
3. **每一项都真生效**：不摆样子，开关之间不冲突；
4. **控件有反馈**：调节时有动画 / 视觉反馈，知道「动了」；
5. **二级设置内联**：进阶设置用「内联 / 底部可预览面板」呈现，**不单独开一页**，不打断阅读流；
6. **改动先问**：涉及 UI / 交互的改动，先给方案确认再做。

> 另外：阅读器中间偏左的亮度调节，对应「左侧竖向滑动手势」，与视频播放器的交互习惯保持一致。

**v2.0.0-beta.2 重点增强**：双页模式（宽屏左右并排）、整本页码、双语 / 段落翻译（AI）、AI 章节配图、AI 阅读总结 / 内容摘要、阅读器内正文编辑、墨水屏主题、书源 JS 简繁函数、Mobi / PDF 便携文档解析、压缩包批量导入、阅读进度 WebDAV 逐书细粒度云同步、EPUB 导出自定义模板 + WebDAV 上传、划线 / 高亮 / 摘录 / 分享、在线多音色 TTS、平滑自动翻页与书签角标自定义图等。

**已具备能力（常驻）**：

- **排版细节**：寡行控制（避免段落末行只剩一两个字孤零零吊在页首 / 页尾）、字号 / 行距 / 段距 / 边距 / 字距、背景预设与自定义色、阴影 / 下划线 / 斜体、章节标题对齐与独立字体缩放、页眉页脚 9 种内容组合、正文字体与标题字体可分别指定。
- **阅读辅助**：睡眠定时（到点自动停止）与后台常亮；点按分区翻页（屏幕分区，各区动作可配置）；书签（按书 / 章 / 页三级）与笔记（按书 / 按章）。
- **本地与导入**：EPUB 懒加载并按 NCX / spine 解析目录；TXT 按内部标题切分章节；TXT 导出。
- **同步**：WebDAV 备份 / 恢复（收藏 + 进度），可跨设备迁移。
- **书架**：空分组自动隐藏，长列表不至于被空分类撑满。

## 2.6 影视播放器（含弹幕）

- 基于 `media_kit`（libmpv 内核）提供跨平台硬解播放能力，并内置解码异常自动降级与播放统计面板；
- 配合 `canvas_danmaku` 做**弹幕渲染**（支持接入弹弹 play 等开放弹幕网络，按标题自动匹配弹幕池），营造「一起看」的氛围；
- 针对「播放线路选择、集数去重、播放界面交互」做过专项优化，减少「选了播不了 / 集数重复 / 切集卡顿」等糟心问题。

**播放器手势与交互：**

- **单击画面**：显示 / 隐藏控制栏（点一下即切换显隐，更顺手）；
- **双击画面中间**：播放 / 暂停；**双击左半屏**：快退 10 秒；**双击右半屏**：快进 10 秒；
- **长按画面**：临时切到自定义倍速加速（松手恢复），倍速值可在「播放器更多菜单」或「设置 → 播放器设置 → 长按播放速度」中自定义（默认 2.0x）；
- **左右横滑**：拖动定位（进度预览），可在设置中调整 seek 倍率（0.5x / 1x / 2x）；
- **左半屏竖滑**：调亮度；**右半屏竖滑**：调音量；
- **缓冲加载动画**：播放中缓冲时画面中央显示转圈，不再"黑屏无反馈"；
- **解析进度条**：点开一集「找视频地址」时，顶部显示细进度条（类似网页加载条），分嗅探 / 解析两段推进；
- 播放器「更多」菜单与「设置 → 播放器设置」提供：解码模式、音频通道、画面比例、默认倍速、默认音量、自动连播、方向锁定、字幕样式、长按播放速度等，**设置项真正生效**（播放器启动时读取并应用）。
- **v2.0.0-beta.2**：新增 Anime4K 超分辨率（效率 / 质量两档）、登录弹弹 play 后发送弹幕、缓存策略降级（蜂窝 / 低内存自动降档）、错误分级重试（切集自动重开自愈）、声明式播放器菜单、字幕按视频记忆、防重叠轨道算法、seek 后弹幕位置稳定等。
- **v2.0.0-beta.2**：画中画与投屏补齐生命周期——系统画中画进入时记录位置、退出后续播，小窗支持播放 / 暂停、弹幕、快进三动作，不满足条件不进入；投屏支持与设备位置双向同步、错误上报、断开自动暂停；桌面端画中画改为缩小窗口置顶的小窗，可拖动，关闭后恢复原窗口。

## 2.7 视频嗅探引擎（v0.3.0 新增）

当源的视频解析失败时，还有一道兜底：内置嗅探引擎借鉴猫爪（cat-catch）等开源项目的「网络拦截 + DOM 检测 + API 钩子」方法论，从播放页中嗅探真实视频地址（m3u8 / mp4 等），并支持把嗅探结果并入源视频抓取流程，弥补源解析失败的情况。

- 支持设置自定义嗅探脚本（可在设置页配置，默认内置一份通用嗅探规则）；
- 嗅探到地址后支持携带 Referer / User-Agent 等防盗链头播放。

## 2.8 下载管理

支持内容离线下载、下载设置与任务管理，方便在无网络（地铁、飞机、流量贵）环境下继续阅读 / 观看。

## 2.9 Bangumi 同步（v0.4.0 新增）

把本地的追番 / 追漫 / 追书进度同步到 [Bangumi 番组计划](https://bgm.tv)：

- **两种登录**：OAuth 2.0 授权登录（浏览器授权后回跳应用，自动续期）或手填个人 Access Token；凭据存放在系统安全存储中；
- **同步内容**：收藏状态（想看 / 在看 / 看过）、动漫已看集数、漫画 / 小说阅读进度、本地评分与短评；
- **策略保守**：以本地推送为主，状态只进不退、进度只增不减，不覆盖你在 Bangumi 上的「搁置 / 抛弃」；只有本地空缺时才回拉评分 / 短评；
- **条目绑定**：本地条目与 Bangumi 条目按标题相似度自动匹配（阈值 ≥0.85），否则给出候选列表手选，可随时解绑；
- **详情页 Bangumi 标签页**：评分、收藏统计、简介、集数与放送日期、标签、角色、关联作品与吐槽；
- **v0.4.1 增强**：详情页一键同步（精确到某一集 / 某一章）、手动单集 / 单章同步、同步弹窗多选、增量同步 + 冲突检测与状态明细、统一备份归档、记住播放 / 阅读位置开关；
- **代理 / 镜像**：可分别指定主站、API、图片域名，应对官方域名直连不畅。

> OAuth 应用凭据通过**编译期注入**、不写入源码。官方发布包已注入；自行构建时未注入则 OAuth 按钮不可用，请改用 Access Token，或到 [bgm.tv/dev/app/create](https://bgm.tv/dev/app/create) 注册应用（回调地址填 `nexhub://oauth/callback`）后用 `--dart-define=BANGUMI_CLIENT_ID=... --dart-define=BANGUMI_CLIENT_SECRET=...` 构建。

> 云同步：v2.0.0-beta.2 起，小说阅读进度支持 **WebDAV 逐书细粒度同步**（一书一文件、退后台静默上传、冲突自动裁决）；收藏 / 设置等通用备份仍以本地导入导出与 Bangumi 同步为主。

## 2.10 网络配置：全局 + 源级覆盖（v0.4.0 新增）

把「连不上、解析被污染、要走代理」这类问题交回给用户自己解决，而不是等源作者改源：

- **全局设置**：代理（直连 / 跟随系统 / 手动，支持 HTTP 与 SOCKS5 及账号密码）、DNS（系统 / 自定义 UDP / **DoH** / **DoT**，内置 Cloudflare、Google、Quad9 预设，可开缓存）、自定义 Hosts、SNI、ECH；
- **源级覆盖**：每个源都能对「代理 / DNS / SNI / ECH / Hosts」逐项选择「继承全局」或「单独覆盖」；源 JSON 也可自带 `network` 块下发推荐配置；
- **生效优先级**：用户覆盖 > 源 JSON 的 `network` 块 > 全局设置 > 默认值；
- **作用范围**：全局配置覆盖整个应用的网络请求（含封面图加载、下载器），DNS 带 TTL 缓存并优先命中自定义 Hosts；**改完即时生效，无需重启**；
- **内置测试**：代理测试、DNS 测试、DoH 测试。

> **SNI 对 https 直连真实生效**：可自定义 SNI 值，或填 `-` 完全不发送 SNI（免 SNI，配合自定义 Hosts 钉定可达 IP 可绕过按 SNI 的连接阻断）；设置页新增「域名 → SNI 映射」编辑与「测试 SNI 握手」按钮。
>
> ⚠️ 诚实的限制：**ECH** 受 Dart TLS 栈限制**运行时暂未接通**——受限站点请优先使用免 SNI / 自定义 SNI + Hosts 组合，或经支持 ECH 的本地代理内核（手动代理，如 mihomo / sing-box）。

## 2.11 收藏分组、本地评分与评论（v0.4.0 新增）

- **多分组**：一个条目可同时属于多个分组（标签式），与源站题材分类互不干扰；分组**按模块隔离**（动漫 / 漫画 / 小说各自独立），可**隐藏**、可拖拽重排、可重命名；删除分组只解除关联，不删条目；
- **多选筛选**：分组栏支持同时选中多个分组做并集筛选；书架筛选新增「分组」维度（含「未分组」）；
- **本地评分与短评**：0–10 分 + 一句短评，可作为 Bangumi 同步内容一并推送；
- **评论**：详情页「评论」标签分「网站评论」（来自源站，支持发表 / 回复 / 点赞 / 举报，具体取决于源声明了哪些路由）与「Bangumi 吐槽」（只读，无需登录）。

## 2.12 源登录鉴权（v0.4.0 新增）

对需要登录才能看内容的源：

- **网页登录（WebView）**：内嵌 WebView 打开站点登录页，成功后自动捕获会话 Cookie；
- **手动粘贴 Cookie**：桌面端等无 WebView 场景的降级方式；
- **API Key 登录**：源声明 `comments.login.sendTokenAs = "key"` 时，用户在「源详情 → 登录」粘贴密钥，App 存本地密钥库，并在受保护请求上追加 `Authorization: Key <密钥>`（前缀可用 `authScheme` 改，密钥参数名可用 `apiKeyParam` 改）。适合「登录给的是 access_token、但收藏 / 个人页接口要单独 API Key」的站点；
- 登录态自动识别与刷新，支持**退出登录**（只清该站点会话，不影响其他源）。

## 2.13 源管理（v0.4.1 重构）

- **源库订阅 / 挑选导入**：可从源库浏览、挑选并一键导入，不再只能手动粘贴 JSON；
- **全字段编辑**：源管理内支持对源 JSON 字段进行可视化编辑；
- **源登录修复**：修复部分源在「源管理」页登录态识别与刷新的问题。

## 2.14 年龄限制体系（v0.4.1 新增）

- 完善的年龄限制策略：源可声明 `ageRating`（`general` 全年龄 / `teen` 青少年 16+ / `mature` 成人 18+）；
- **18+（mature）源在默认设置下自动隐藏**，可手动开启显示；
- 网络收藏与源管理均遵循年龄限制过滤。

## 2.15 源公告与网络收藏（v0.4.x 新增）

- **源公告 `announcement`**：源作者可在源 JSON 里声明公告（如「站点换域名」），应用在源的首页 / 详情页顶部以横幅展示，app 不写死任何站点文案；
- **网络收藏 `webFavorite`**：若源站自身提供「书架 / 收藏」网页，源可声明网络收藏配置，让在线浏览页多出一个「网络收藏」Tab（走源站账号，与 App 本地收藏相互独立），详情页 / 阅读器 / 播放器也可提供「加入网络收藏」。

## 2.16 RSS 订阅

内置可配置的 RSS 路由，可订阅如动漫资讯等公开 RSS 源，在应用内直接阅读更新。

## 2.17 历史与更新追踪

## 2.21 猜你喜欢（源能力）

- **推荐路由**：源在 `routes` 里声明 `recommend`（优先）或 `related`，详情页打开时用 `{id}` 变量调用，结果以「猜你喜欢」区块展示（两者都未声明则不显示）；
- **漫画**：可用 `selectors.detail.recommendations`（`list` / `title` / `cover` / `url`）从详情页直接抽取推荐列表；
- **小说（Legado 兼容）**：用 `ruleBookInfo.recommendations` 抽取推荐书名；
- 推荐结果复用列表解析引擎，字段与搜索 / 最新一致，**由源作者声明，App 不写死任何站点推荐逻辑**。

## 2.22 漫画页翻译（MTL · v2.0.0-beta.3 新增）

跨语言看漫画的门槛，靠「机翻嵌字」降下来：

- **翻页即翻**：翻到一页时自动对该页做视觉 OCR + 翻译，译文气泡按视口 / 宽高比 / 阅读模式映射叠加到原图对应位置；
- **按作品记忆**：开关在长按菜单与阅读设置面板里，按「作品」记忆你的偏好，失败可重试；
- **四级缓存**：译文按「作品 | 章 | 页 | 语言」缓存，翻回去看过的页秒开；
- **稳定性加固**：引入并发信号量（网络请求上限 2，缓存命中不占槽），快速翻页不再触发 429 限流；
- **专属接口**：设置页「漫画翻译」可填独立 AI 接口（留空回落通用翻译）。

## 2.23 视频字幕实时翻译（v2.0.0-beta.3 新增）

影视跨语言，靠「字幕实时翻译」补上：

- **字幕面板开关**：跨会话记忆，节流读取播放器字幕逐句翻译；
- **无字幕兜底**：没有字幕轨时截帧做画面 OCR 兜底；
- **原文可选**：译文底部覆盖层可切换是否同时显示原文；按「语言 | md5」持久缓存；
- **不丢句**：单句翻译指数退避重试（最多 3 次），瞬时网络抖动不再丢句；
- **专属接口**：设置页「视频翻译」可填独立 AI 接口（留空回落通用翻译）。

> 漫画页翻译 / 视频字幕实时翻译依赖 AI 接口配置；未配置时回落通用翻译或不可用。

## 2.24 划线 / 高亮 / 摘录 / 分享（小说阅读器）

读小说时遇到金句，不用跳出 App 就能收藏与分享：

- **触发**：在小说阅读器内**长按选词 / 选句**，弹出操作条：划线、高亮、摘录、分享；
- **划线 / 高亮**：按「书」持久化，重进该书仍可见；高亮用颜色标记重点段落，便于回看与复习；
- **摘录**：选中的句子归入该书「摘录 / 笔记」，可在笔记里统一浏览、管理、删除；
- **分享卡片**：生成一张「书封 + 渐变文艺卡片」样式的分享图（基于 `share_plus`），把金句连同书名 / 封面一键分享到其它应用；
- 这些操作只动本地数据，不影响源站点，也不上传任何内容。

## 2.25 更新通道与版本升级（测试版通道 / SemVer）

想第一时间用上新功能，又不想被不稳定版本打扰，靠两条升级通道分开：

- 应用内「设置 → 关于 / 更新」可检查新版本，区分**稳定版**与**预发布**两条通道；
- 版本比较按 **SemVer** 规则：核心版本相同则逐段比较预发布号，修复了「beta.1 → beta.2 同核心迭代被判为已是最新」导致测试版通道收不到更新的问题；
- 预发布通道按 tag 识别 **alpha / beta / rc**，可逐级升级（alpha < beta < rc < 正式版），稳定版通道自动过滤预发布 tag；
- 想抢先体验开「预发布通道」，求稳的用户留在稳定版即可；升级沿用同一签名密钥，可直接覆盖安装。

## 2.26 阅读统计

回顾「看了多少、看了多久」，数据全在本地：

- 本地记录**阅读时长**与**阅读进度**，按「天」聚合（日维度统计），不依赖任何账号、不上传；
- 覆盖**小说 / 漫画 / 影视**三端阅读器，统一在各阅读器埋点上报；
- 可在「设置 / 关于」或对应统计入口查看累计与近期数据，方便自我复盘与找回上次看到哪。

## 2.27 弹幕渲染与接入（影视播放器）

影视播放器内置弹幕能力，营造「一起看」的氛围：

- 基于 `canvas_danmaku` 做弹幕渲染，与 `media_kit` 播放画面叠加；
- **弹幕来源**：可接入弹弹 play 等开放弹幕网络，按「标题 / 集数」自动匹配弹幕池；部分源需登录弹幕账号后才能拉取 / 发送；
- **渲染细节**：beta.2 起含防重叠轨道算法、seek 后弹幕位置稳定、字幕按视频记忆；登录弹弹 play 后可发送弹幕；
- 弹幕开关与基础样式在播放器「更多」菜单 / 设置中可调；未接入弹幕源的影片则不显示弹幕层。
